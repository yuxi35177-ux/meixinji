# 没心机本地 APK

应用名称：没心机·本地版。包名：`com.meixinji.local`。沿用原本地包的图标状态（原包未指定图标）、WebView 数据目录和页面 origin。内置完整网页资源，不依赖 Vercel 启动；调用模型仍使用用户自行保存的地址、模型、密钥。

## 功能入口

我的 → 表情包下方的「感知」。独立页面内逐项开启、授权，底部逐项测试；主开关默认关闭。未授权、不支持硬件、当前没有信号均显示实际状态，不会伪造读数。健康睡眠依赖可用的 Health Connect 及数据源；步数为基线后估算；截屏需 Android 11+ 和无障碍授权，画面先本机预览，确认后才放入聊天。当前使用截图、悬浮球、小组件、震动均为用户操作，不会自动发送截图。

我的 → 设置 → 外观：跟随系统 / 日间 / 夜间；字号快捷滑块与原衣橱全局字号共用同一设置，不重置自定义字体。原双向返回逻辑保留，Android 系统返回连接到同一层级。

HTML 历史消息打开时自动识别卡片，原文保存在 `originalHtmlContent`；支持混合正文、HTML 实体、代码块、完整文档、可恢复的残缺标签。自由 HTML 用禁脚本的隔离 iframe 渲染，原有 xxj-ih 内置卡片保留原渲染与互动，宽度随手机适配，展开内容自动增高，字号随全局设置。新密谈默认开启 HTML 自动插卡，原密谈显式关闭选项仍有效。

## 构建

JDK 17、Gradle 8.11.1、Android SDK 36 和 Build Tools 35.0.0：

```sh
gradle -p android-app assembleDebug lintDebug
```

Gradle 自动将根目录页面、脚本、样式、图标和 vendor 打包到 assets/www。API 原生传输限定本应用主页面 origin，支持配置的本机、局域网和云端 AI 地址及流式取消；卡片无权执行脚本。MiniMax 代理在 APK 中直接转发到其官方接口。

## 数据与更新

旧版 1.0 的 GitHub Actions 临时 debug 签名无法从 APK 还原。本次新包签名与旧版不同，Android 不能直接覆盖旧版；先从旧版「备份与导入」导出 ZIP，确认备份保存成功后再迁移安装并导入。不要未备份就卸载。新包的签名密钥单独保管，未提交仓库。后续更新必须使用同一密钥。
