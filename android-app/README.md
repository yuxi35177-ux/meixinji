# 没心机本地 APK

应用名称：没心机·本地版。包名：`com.meixinji.local`。使用原网页版的粉发人物图标、WebView 数据目录和页面 origin。内置完整网页资源，不依赖 Vercel 启动；调用模型仍使用用户自行保存的地址、模型、密钥。

## 功能入口

我的 → 表情包下方的「感知」。独立页面内逐项开启、授权，底部逐项测试；主开关默认关闭。未授权、不支持硬件、当前没有信号均显示实际状态，不会伪造读数。健康睡眠依赖可用的 Health Connect 及数据源；步数为基线后估算；截屏需 Android 11+ 和无障碍授权，画面先本机预览，确认后才放入聊天。当前使用截图、悬浮球、小组件、震动均为用户操作，不会自动发送截图。

我的 → 设置 → 外观：跟随系统 / 日间 / 夜间；字号快捷滑块与原衣橱全局字号共用同一设置，不重置自定义字体。原双向返回逻辑保留，Android 系统返回连接到同一层级。

HTML 历史消息打开时自动识别卡片，原文保存在 `originalHtmlContent`；支持混合正文、HTML 实体、代码块、完整文档、可恢复的残缺标签。自由 HTML 用禁脚本的隔离 iframe 渲染，原有 xxj-ih 内置卡片保留原渲染与互动，宽度随手机适配，展开内容自动增高，字号随全局设置。新密谈默认开启 HTML 自动插卡，原密谈显式关闭选项仍有效。

## 构建

JDK 17、Gradle 8.11.1、Android SDK 36 和 Build Tools 35.0.0：

```sh
gradle -p android-app assembleDebug lintDebug
```

Gradle 自动将根目录页面、脚本、样式、图标和 vendor 打包到 assets/www。API 原生传输限定本应用主页面 origin，支持配置的本机、局域网和云端 AI 地址及流式取消；卡片无权执行脚本。MiniMax 代理在 APK 中直接转发到其官方接口。

## 数据与更新

旧版 1.0 的 GitHub Actions 临时 debug 签名无法从 APK 还原。本次新包签名与旧版不同，Android 不能直接覆盖旧版；先从旧版「备份与导入」导出 ZIP，确认备份保存成功后再迁移安装并导入。不要未备份就卸载。新包的签名密钥单独保管，未提交仓库。后续更新必须使用同一密钥。

## 1.2 更新：全局字号、MCP 与界面优化

- 字号默认 14px，原有手动设置保留。统一缩放内置应用的 rem、px、vw 字号，HTML 卡片随字号联动，关闭 WebView 额外的系统文字放大。
- 人物介绍卡右上角可收起／展开，状态在本机记住。手机壳按视口高度固定，列表滚动不再把顶部返回按钮推出屏幕。
- 截屏、悬浮窗底部测试区提供「打开权限」和「应用信息」。测试发现缺权限时也会打开系统入口；原生跳转在 UI 线程执行并提供备用入口。系统受限制的设置仍须用户在应用信息中手动允许，APK 不会自动批准权限。
- HTML 可展示性判断采用有容量限制的缓存，同一张卡不重复解析；iframe 高度更新按帧合并，清理失效观察器，隐藏时停止测量；长感知列表按可见区域绘制。
- 我的 → 感知下方「MCP 工具」：保存多个 HTTP／SSE 地址，支持 Bearer 密钥、自定义请求头、Float／通用 JSON 配置导入、连接测试、工具发现与手动调用。地址和密钥仅保存在本机。
- 在 MCP 中打开聊天开关后，支持 OpenAI function/tool calling 的模型可请求工具，执行前逐次展示名称与参数让用户确认。最多四轮工具交互，继承聊天取消信号。MCP 未开启时聊天链路不变。
- 支持 MCP 2024-11-05 的旧 SSE，以及 2025-03-26／2025-06-18／2025-11-25 的 Streamable HTTP，包括会话头、事件流响应和工具分页。stdio 必须先提供 HTTP 网关；当前版本不提供 OAuth 浏览器登录或令牌自动刷新，可填 Bearer 令牌／自定义头，或导入 Float 已有 accessToken。
- 原生 MCP 传输只接受主页面注册的服务地址，SSE 消息入口必须同源；不会通过 Vercel 转发。协议参考 https://modelcontextprotocol.io/specification/2025-11-25 。

额外验证：安装 Playwright 后运行 `node tests/mcp-ui.browser.cjs`，本地模拟服务覆盖 HTTP、SSE、会话、分页、请求头、工具调用、确认／拒绝，以及全局字号、人物卡折叠和权限按钮。
